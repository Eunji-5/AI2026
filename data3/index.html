1. 프로젝트 개요

공공데이터 시각화로
어린이 안전 환경을 직관적으로 탐색

전국어린이보호구역표준데이터.csv 총 14,647건을 정제하여, 특정 지역의 시설 종류, CCTV 설치 상태, 도로 폭 정보 등을 빠르게 조회하고 분석할 수 있는 최적의 Web 지도 서비스를 제공합니다.

초고속 클러스터링

1.4만건 데이터를 끊김 없이 렌더링하는 Leaflet.markercluster 연동

다차원 실시간 필터

시설종류별, CCTV 여부별, 키워드 검색을 결합한 다중 조건 조회

데이터 요약 및 처리 명세
EUC-KR Decoding
데이터 소스 전국 어린이 보호구역 표준 데이터
지원 시설 구분 초등학교, 유치원, 어린이집, 특수학교 등
지능형 예외 처리 도로명주소/지번주소 폴백 및 도로폭 Null 체크
실시간 통계 인디케이터 필터 적용 시 CCTV 설치율(%) 즉시 재계산
2. 주요 기능 및 요구사항

핵심 기능 명세서 (Requirements)

사용자 중심의 가독성과 빠르고 유연한 인터랙션을 고려한 기능 요구사항입니다.

2.1 지도 및 마커 시각화

Leaflet & 클러스터링

  • Leaflet.js + OpenStreetMap 기반으로 API Key 부담 없이 구동
  • Leaflet.markercluster로 1.4만개 대용량 마커 병목 제거
  • CCTV 설치 여부별 마커 색상 이분화 (설치: 파랑, 미설치: 빨강)
2.2 사이드바 & 필터링

스마트 검색 및 필터

  • 시설종류 필터: 전체, 어린이집, 초등학교, 유치원, 학원 등
  • 키워드 검색: 대상시설명 또는 소재지 주소 실시간 필터링
  • 통계 카운터: 현재 화면 필터 조건에 따른 총 시설 수 및 CCTV 비율 갱신
2.3 마커 카드 팝업

상세 Popup 정보 카드

  • 🏷️ 대상시설명 + 시설종류 배지
  • 📍 소재지 주소 (도로명 우선, 없을 시 지번 자동 대체)
  • 📏 보호구역 도로폭 & 🚔 관할경찰서명 & 📹 CCTV 대수

6. 검증 계획

품질 검증 테스트 케이스

데이터 로딩 검증

14,647개 전체 데이터 세트가 브라우저 단 메모리 랙 없이 빠른 초기 로딩 시간을 준수하는지 파싱 스피드 테스트.

마커 색상 조건 분기 검증

CCTV설치여부 컬럼값이 'Y'인 경우 파란색, 'N'인 경우 빨간색으로 정확히 구분되는지 확인.

필터 동기화 동작 검증

사이드바 옵션 변경 시 클러스터 마커 개수 및 통계 카드(총 시설 수, CCTV 비율)가 오차 없이 실시간 계산되는지 검증.

예외 처리 및 팝업 내용 검증

주소 및 도로폭 필드가 빈값일 때 '-' 표기 예외 처리가 깔끔히 구현되는지 팝업 가독성 점검.
